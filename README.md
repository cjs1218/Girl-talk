# Girl Talk

A friendly web app for girls of about 8 to 10. It helps them build confidence, manage big feelings, set goals and handle tricky friendships. It works on phones and tablets, and you can add it to the home screen.

No accounts, no messaging, no tracking. Everything is saved only in the browser on that device.

## What's inside

| Section | Tools | Based on |
|---|---|---|
| 🦁 **Brave Me** | Super strengths · Brave steps ladder · Kind voice game | Character strengths, graded exposure and cognitive restructuring from CBT |
| 🌈 **Calm Corner** | Feelings check-in (name + size) · Flower & candle breathing · Squeeze & relax · 5-4-3-2-1 senses · Worry sorter · Feelings diary | Affect labelling, slow breathing, progressive muscle relaxation, grounding, CBT problem-solving |
| 🚀 **My Goals** | WOOP goal builder (Wish, Outcome, Obstacle, Plan) with a weekly "I tried" tracker | Mental contrasting with implementation intentions (Oettingen; Duckworth et al., 2013) |
| 💞 **Friendship Tools** | Mouse, Monster or Me? · Six branching friendship stories · Brave words + "I feel" builder · Kind friend or not? · Stop, Think, Do · Who can help me? | Assertiveness and social problem-solving from social-skills training |
| 🧡 **For grown-ups** | Emotion coaching guide, evidence notes, data reset | Gottman's emotion coaching; *Tuning in to Kids* |

Stars are earned for trying things (some once, some once a day), not for getting things "right".

## Run it

It's plain HTML, CSS and JavaScript with no build step.

- **Locally:** open `index.html` in a browser, or run `python3 -m http.server` and go to http://localhost:8000
- **Online:** turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root)

## Changing the words

All the content (stories, phrases, feelings, quiz questions) is in `content.js`, so you can edit it without touching the app logic in `app.js`.

## A note

This is a supportive tool, not therapy. If you're worried about a child's mood, anxiety or bullying, speak to their school or GP. Childline: 0800 1111.
